# Гибридный поиск объявлений для RAG

Ноутбук `avito-bootcamp-v2-final.ipynb` реализует retrieval-часть RAG-системы: по пользовательскому запросу она выбирает из корпуса 50 наиболее релевантных объявлений. Найденные объявления можно передать следующему компоненту RAG как контекст; генерация ответа LLM в этом проекте не реализована.

## Что сделано

- Подготовлены тексты запросов и объявлений, фильтры и географические признаки.
- Построен лексический поиск: BM25 и символьный TF–IDF, устойчивый к опечаткам.
- Дообучены `multilingual-e5-small` и `multilingual-e5-base` на парах «запрос — выбранное объявление».
- Добавлены глобальный и локальный поиск, радиусы 25/50/100 км и переходы между связанными локациями.
- Результаты 46 поисковых каналов объединены взвешенным Reciprocal Rank Fusion (RRF).
- Формируется `answer.csv` с 50 уникальными `item_id` для каждого запроса.

## Как устроена система

Запрос обрабатывается одновременно лексическими и векторными моделями. BM25 ищет точные совпадения слов, символьный TF–IDF помогает с опечатками, а E5 находит объявления, близкие по смыслу. Каждый метод строит несколько списков кандидатов с разным учётом текста, фильтров и географии. RRF объединяет эти списки: выше оказываются объявления, которые хорошо ранжируются сразу в нескольких каналах.

Финальный ансамбль достиг метрики **0.852066**; базовый вариант давал **0.792605**.
